# Personal Portfolio Website

A personal website I built to introduce myself, share my skills and certificates, and showcase some of my early web development projects. It brings together my work in one place and reflects my progress while learning front-end development.

## Website Sections

- **About Me** – A short introduction and my interests in technology.
- **Skills** – Technologies and tools I have learned.
- **Education** – My Information Technology background.
- **Certificates** – Courses and certificates I have completed.
- **Projects** – Small websites and interactive applications I have built.

## Projects Included

- **Al-Qassim Region** – An informational page about cities in the Al-Qassim Region of Saudi Arabia.
- **Score Keeper** – A two-player score counter with a selectable winning score and a reset button.
- **Calculator** – A calculator for basic arithmetic operations.
- **TV Shows Search** – Search for a TV show and view its image, summary, and season and episode counts using the TVmaze API.
- **Athkar (أذكاري)** – An Arabic morning and evening Athkar application with a repetition counter.

The repository also includes an earlier version of the Athkar project.

## Technologies Used

- **HTML** – Page structure and content
- **CSS** – Layout and styling
- **JavaScript** – Interactive features
- **Bootstrap** – Layout and responsive components
- **Axios & TVmaze API** – TV show search feature

## What I Learned

Building this website helped me practice creating web pages, organizing content, styling layouts, and making pages interactive with JavaScript. The smaller projects gave me experience handling user input, updating page content, and working with an external API.

## Project Note

This is a personal learning and portfolio project. It contains several small exercises and showcases the web development skills I was practicing when I built it.
